NEXUS 1.0 — Minimalist Launcher\n\nPublique os arquivos em um site HTTPS (por exemplo GitHub Pages). No Safari do iPhone, abra o endereço e escolha Compartilhar > Adicionar à Tela de Início.\n\nToque em + para adicionar aplicativos. Segure um favorito para editá-lo; na biblioteca use ⋯. Os dados ficam no armazenamento local do navegador e podem ser perdidos ao limpar os dados do site.\n\nLimitações: não captura notificações; não detecta aplicativos instalados; links de abertura de apps dependem do suporte de cada aplicativo. Os atalhos de exemplo são URLs web, não garantem abertura do app nativo.\n
